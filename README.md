# Living Room Lobby: party games for a smart-TV browser where kids without phones and non-English relatives can still play

Live: https://living-room-lobby.sociobot.in — built by the Param Factory (`web-with-backend`).

See `.factory/brief.json` for the researched problem this solves and `.factory/design.md` for the visual system.

## Develop

```
npm install
npm run dev
npm test
npm run build   # -> dist/
```
